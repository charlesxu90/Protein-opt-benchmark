# Supplementary Methods — Benchmarked methods and configurations

> Configurations transcribed from the benchmark implementation. `(ref.)` marks a
> citation to be added. Two code paths are used: on the **four-site** combinatorial
> landscapes each method runs its own implementation (`<method>/run_generic.py`); on the
> **multi-site** learned-oracle landscapes all methods run through a single unified
> generative-proposal script (`scripts/run_oracle_benchmark.py`), in which library-
> enumerating methods are converted to a mutate-from-elites generator so every method
> operates over the same non-enumerable space. Unless noted, each method used the same
> protocol: an initial random batch of 96 followed by four model-guided rounds of 96
> (480 queries total) and 30 random seeds; four-site fitness is an exact lookup, multi-
> site fitness is the trained CNN oracle.

## Basic search

**Random.** Uniform sampling with no model. Four-site: 96 indices sampled without
replacement from the enumerated 20⁴ library each round. Multi-site: 96 fresh random
sequences generated each round. Serves as the lower-bound control.

**GreedyWalk.** Hill-climbing with no surrogate. Each round the best sequence found so
far is taken and its single-mutation neighbours are evaluated directly (four-site: all
neighbours enumerated from the library and ranked by measured fitness, top-96 selected
with random fill; multi-site: single-mutant neighbours generated and scored by the
oracle). Amino-acid alphabet `ACDEFGHIKLMNPQRSTVWY`.

## Supervised / active-learning methods

All four encode sequences as per-position one-hot over the varying positions and select
from either the enumerated library (four-site) or a mutate-from-elites candidate pool
(multi-site; pool size 8,000, 24 elites, up to 2 mutations per step).

**ftMLDE (ref.).** Ensemble regressor with greedy top-N selection.
- Four-site: 5-model MLDE ensemble — XGBoost (100 trees, max_depth 4, lr 0.1), XGBoost
  (gblinear), random forest (100 trees, max_depth 10), gradient boosting (100 trees,
  max_depth 3) and kernel ridge (α = 1.0); predictions averaged; top-96 by predicted
  fitness over the full library.
- Multi-site: a 4-regressor "zoo" (ridge α = 1.0, k-nearest-neighbours k ≤ 5, random
  forest 100 trees, extra-trees 100 trees) cross-validated (≤3 folds), the top-3 by CV
  retained and averaged; top-96 by predicted fitness over the candidate pool.

**ALDE (ref.).** Ensemble regressor with **Thompson sampling** (exploration parameter
ξ = 4).
- Four-site: DNN ensemble (`DNN_ENSEMBLE`, two hidden layers of 30 units, leaky-ReLU,
  one-hot features), trained 300 iterations (lr 1e-3); Thompson-sampling acquisition
  over the full library.
- Multi-site: random-forest surrogate (100 trees); Thompson sampling using the
  predictive mean and the per-tree standard deviation (mean + std·𝒩(0,1)) over the pool.

**CLADE (ref.).** Ensemble regressor with **cluster-stratified** selection.
- Four-site: 4-model ensemble (XGBoost, random forest, gradient boosting, kernel ridge),
  averaged; the library is partitioned by k-means (k = 10) and the top-predicted
  variants per cluster are selected.
- Multi-site: 3-model ensemble (ridge, random forest, k-nearest-neighbours), averaged;
  the candidate pool is partitioned by MiniBatchK-means (k = batch) and the best-
  predicted sequence per cluster is selected.

**MULTI-evolve (ref.).** Bootstrap fully-connected neural-network ensemble with greedy
top-N selection.
- Four-site: FCN ensemble (2 layers, 100 units, Adam, batch 32) on one-hot mutation
  encodings; top-96 by predicted fitness over the library.
- Multi-site: 3-network bootstrap FCN ensemble (256→64 units, ReLU, Adam lr 1e-3, weight
  decay 1e-4, 120 epochs, per-network bootstrap resampling); top-96 by mean prediction
  over the pool.

**EVOLVEpro (ref.).** Frozen protein-language-model embeddings with a random-forest
top layer. Sequences are embedded with **ESM-2** (`facebook/esm2_t12_35M_UR50D`,
mean-pooled, 480-dim); a random forest (100 trees four-site / 200 trees multi-site) is
trained on the queried labels and the top-96 variants by predicted fitness are selected.
On multi-site the candidate pool is capped at 2,000 sequences per round to bound the
ESM-2 embedding cost.

## Structure-guided design

**AiCE (ref.).** ProteinMPNN-conditioned per-position amino-acid frequencies, no learned
regressor. Structure-conditioned frequencies are obtained from ProteinMPNN
(1,000 sequence samples at temperature 0.5) and blended with the per-position
frequencies of the highest-fitness observed variants, with the observed weight increased
across rounds (≈0.2 → 0.7). Candidates are generated by sampling mutations at varying
positions from the blended distribution and ranked by summed log-frequency; on four-site
a linkage-disequilibrium bonus is added for multi-mutations. Per-dataset structures /
precomputed ProteinMPNN frequency tables are used.

## Generative / policy-based search

**AdaLead (FLEXS) (ref.).** Model-guided evolutionary search by recombination and
mutation of high-fitness parents.
- Four-site: FLEXS AdaLead with a 5-model CNN ensemble surrogate (32 filters, hidden
  100, kernel 3, 20 epochs each); library-aware mutation (only observed positions/amino
  acids); top-96 by surrogate score, ≤2,000 model queries per round.
- Multi-site: two-wave recombination (20% recombination rate) + mutation from elite
  parents, scored by a CLADE-style 3-model ensemble, top-96 by predicted fitness.

**AlphaVariant (this work).** GPT sequence prior optimized by augmented-likelihood
REINFORCE against a 5-model surrogate ensemble; full configuration (including the
four-site bare+finetune and multi-site oracle settings) is given in the main Methods and
the AlphaVariant configuration table. Briefly: 4-layer GPT generator; UCB surrogate
reward (σ = 60); cluster-based round-1 initialization; per-round CLADE-style cluster
selection of the proposal pool; four-site uses an in-run prior finetuned each round on
collected sequences (aa+one-hot surrogate features); multi-site uses a homolog-pretrained
prior, EV-augmented surrogate features, a ≤2-mutation cap and a SHAP-pruned proposal
alphabet.

## Notes

- **Additional method (not in the main comparison).** δ-Conservative Search (delta_cs;
  BioSeq-GFN-AL (ref.)) was also evaluated on the four-site landscapes: a GFlowNet
  generator with a dropout-uncertainty MLP proxy (2 layers, 256 units) and a
  delta-conservative (radius-bounded) UCB acquisition, under the same 96 × 5 budget. It
  is reported in the supplementary tables only and is excluded from the main figure.
- **Shared settings.** All methods used batch size 96, five rounds (480 queries) and the
  unified metric pipeline; min–max normalized fitness; medians over 30 seeds with
  paired Bonferroni-corrected Wilcoxon tests for significance (main Methods, Statistics).
- Each method was run in the configuration recommended by its original authors, adapted
  only as described above for the multi-site generative-proposal setting.
